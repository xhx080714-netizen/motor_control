# sand_rake_vision

## 负责人

- 同学 C — 球体数据与模型训练
- 同学 D — 车机环境与 RKNN 部署

## 功能定位

本包负责耙沙捡球车的相机图像接入、球体检测模型推理和检测结果发布，覆盖从训练模型交付到 RK3576 车机 RKNN 部署的运行链路。

## 主要职责

- 接入相机图像并支持通过 YAML 配置分辨率和帧率。
- 约定模型输入尺寸、颜色格式、归一化、类别、置信度和 NMS 参数。
- 接收训练侧交付的 ONNX 模型并转换为 RKNN 模型。
- 在 RK3576 NPU 上执行球体检测推理。
- 发布包含类别、检测框和置信度的检测结果。
- 对比 PC 端 ONNX 与板端 RKNN 推理结果，执行固定图片回归。
- 统计检测频率、推理耗时、资源占用和故障诊断状态。

## 接口说明

以下内容均为三周计划中的计划接口，Day 1 阶段尚未实现：

- 输入：`/camera/image_raw`。
- 输出：`/vision/ball_detections`，计划使用 `vision_msgs/msg/Detection2DArray`。
- 配置：相机参数、模型路径、模型前后处理参数和检测阈值。

最终的 Topic 名称、消息类型、频率、超时和 `frame_id` 以 `docs/icd_v0.1.md` 为准。
