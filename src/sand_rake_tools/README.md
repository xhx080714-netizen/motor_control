# sand_rake_tools

## 负责人

同学 A — ROS 2 平台与集成

## 功能定位

本包用于存放耙沙捡球车项目中可复用的命令行工具和辅助脚本，为系统集成、数据处理、运行检查和测试取证提供支持。

## 主要职责

- 提供关键 Topic 的 rosbag 录制与回放辅助脚本。
- 检查相机、激光、检测和底盘等关键 Topic 是否存在、频率是否正常以及是否超时。
- 提供演示启动前的环境与接口检查工具。
- 收纳团队共享的数据抽帧、结果整理和测试辅助工具。
- 保证脚本不依赖个人绝对路径，并能够在干净终端中重复执行。
- 为集成测试输出带日期、版本和日志位置的可追踪结果。

## 接口说明

本包以命令行工具为主，不定义固定的运行时 ROS 2 接口。计划中的工具将读取或记录相机、激光、检测、安全和底盘相关 Topic；Day 1 阶段尚未实现这些工具。

工具涉及的 Topic 名称、消息类型、频率和超时以 `docs/icd_v0.1.md` 为准。
