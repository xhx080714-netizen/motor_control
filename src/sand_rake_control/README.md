# sand_rake_control

## 负责人

同学 B — 底盘运动与安全控制

## 功能定位

本包负责耙沙捡球车的人工遥控、差速运动解算、底盘通信和安全裁决，确保所有运动命令经过安全状态机后才能发送到底盘。

## 主要职责

- 实现差速运动学解算和 Mock 底盘节点。
- 实现 W/S/A/D/Q/E、空格等键盘遥控功能，并限制最大速度。
- 实现 READY、RUNNING、STOP_LATCHED、FAULT 安全状态机。
- 在遥控命令超时、障碍事件或设备故障时输出停车命令。
- 实现底盘协议编解码、真实底盘驱动和反馈状态发布。
- 完成轮向、轮距、速度增益、加速度和停车参数标定。
- 保证障碍移除后不会自动恢复运动，必须由人工确认复位。

## 接口说明

当前已实现的主要接口：

- 输入：`/teleop/cmd_vel`、`/safety/event`。
- 输出：`/safety/cmd_vel`、`/chassis/wheel_rpm_cmd`、
  `/mock/chassis_state`、`/mock/wheel_rpm_feedback`、`/chassis/odom_raw`。
- 配置：底盘结构参数、速度上限、安全超时和通信参数。

最终的 Topic 名称、消息类型、频率、超时和单位以 `docs/icd_v0.1.md` 为准。

## 当前状态

安全裁决、键盘遥控、差速运动学、Mock 底盘及 Modbus/RS232 基础层已实现并有
自动化测试。正式四轮硬件命令管线仍需完成现场轮位和方向标定。
