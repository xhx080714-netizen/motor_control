# sand_rake_interfaces

## 负责人

同学 A — ROS 2 平台与集成

## 功能定位

本包集中定义耙沙捡球车各 ROS 2 模块共享的自定义消息、服务和动作接口，避免不同模块重复或不一致地定义通信数据。

## 主要职责

- 维护跨 package 使用的自定义 ROS 2 接口。
- 首期定义统一的安全事件消息 `SafetyEvent.msg`。
- 保证 Python 和 C++ 节点均可生成并使用接口代码。
- 配合接口控制文档统一字段含义、单位、频率、超时和坐标系。
- 对接口变更进行集中管理，冻结后避免破坏性修改。

## 接口说明

当前接口：

- `SafetyEvent.msg`：包含时间戳、是否停车以及事件原因枚举。
- 首期安全事件原因包括激光障碍和传感器超时等场景。

消息的最终字段、枚举值和使用约束以 `docs/icd_v0.1.md` 为准。

## 当前状态

`SafetyEvent.msg` 已实现，并提供 C++/Python 测试发布器。控制包已改为使用本包
的共享消息，不再维护重复定义。
